NOAA HRRR 48 h forecast (3 km CONUS) in the browser

duckdb-wasm + the zarr extension built for wasm. Store: https://data.source.coop/dynamical/noaa-hrrr-forecast-48-hour/v0.1.0.zarr (dynamical.org, Zarr v3 with sharding, read directly: Source Cooperative sends CORS and Range headers). Dims: init_time (runs every 6 h since 2018-07-13), lead_time (seconds, 0..48 h), y, x (metres on the HRRR Lambert conformal grid). One shard per run; inner chunks are 265 x 300 cells across all 49 leads, so a small box over a whole run costs one chunk. Bound scans with ranges=['dim:lo:hi', ...]: ISO times on init_time, raw values elsewhere, inclusive.
